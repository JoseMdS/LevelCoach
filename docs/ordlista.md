# Ordlista

Gemensamma begrepp (LLD, ADR, epic, krav …) finns i den [centrala ordlistan](https://josemds.github.io/dev-portal/ordlista/). Här står bara det som är specifikt för LevelCoach.

| Begrepp | Betydelse |
|---|---|
| **Filler** | Specens kärnförmåga som visas dimmad när inget annat kan föreslås. |
| **Spec** | Talangträdet med flest poäng, eller det som tvingats med `/lc spec`. |
| **Twisting** | Seal- eller totem-twisting: att växla mellan två effekter för extra skada. |
| **Uppskattning** | Värden (resurs, cooldown, buff) som räknas fram från egna kast när Forever döljer dem. |
| **WoW Forever** | Blizzards Classic-era-server med egna klassändringar (lansering 4 nov 2026). |
